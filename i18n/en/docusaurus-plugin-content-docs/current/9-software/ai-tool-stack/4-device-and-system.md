# Device Management & System Settings

## Device Management

- **NE101/NE301 device support**: devices connect to AIToolStack with real-time online/offline status, basic info and status management
- **Device-project binding**: bind devices to AI model projects — collected images are automatically routed to the matching project space for batch training and dataset organization
- **Device info & traceability**: manage device names and query historical collection/reporting data for traceability

![Device Management](/img/aitoolstack/devicemanage.webp)

## System Settings

- **Multi-MQTT-broker management**: subscribe to and manage multiple external MQTT brokers simultaneously for multi-scenario data collaboration
- **MQTTS encryption**: the built-in MQTT broker supports MQTTS — configure broker parameters (certificates, ports, permissions) in the UI
- **MQTT certificate management**: import, generate and one-click switch between certificate sets for secure device-server access
