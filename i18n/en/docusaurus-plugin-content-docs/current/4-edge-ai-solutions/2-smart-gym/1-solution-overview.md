# Solution Overview

## 1.1 Solution Introduction

Smart Gym: **one device only — the NeoEyes NE503 edge AI camera.** Each unit runs capture → 20 TOPS NPU inference → structured events in-camera: real-time occupancy, footfall trends, equipment-zone utilization and safety alerts. Zero cloud dependency, no extra compute box.

- **What**: an in-store operations sensing solution on end-to-end AI cameras
- **Problem**: no occupancy data, no utilization data, late safety-event discovery
- **Who**: gym chains and single stores, store-SaaS vendors
- **Outcome**: live occupancy display, utilization reports, second-level safety alerts

## 1.2 Solution Value

**Business**: capacity control backed by data; equipment & class planning from utilization; faster incident response.

**Technical**: single-device end-to-end; zero cloud; 20 TOPS multi-model concurrency.

**Deployment**: IP67 + PoE single-cable install; validated official apps (zero dev); starter = 3 cameras + 1 PoE switch.
