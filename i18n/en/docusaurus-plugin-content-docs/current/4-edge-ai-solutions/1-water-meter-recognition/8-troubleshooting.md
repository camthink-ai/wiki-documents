# Troubleshooting

| Problem | Possible Cause | Solution |
|---|---|---|
| Camera offline | battery / network | check battery, re-provision network |
| No images at platform | uplink config | verify Webhook/MQTT settings |
| Empty recognition | ROI missing/too small | re-frame the ROI |
| Reading jumps | mid-carry wheel state | enable consistency rule |
| Low confidence | light/glare/dirt | fill light, clean dial, adjust angle |
| Business got nothing | Data Push policy | check push status and retries |

Platform-side issues: [NeoMind troubleshooting](/docs/neomind/user-guide/troubleshooting).
