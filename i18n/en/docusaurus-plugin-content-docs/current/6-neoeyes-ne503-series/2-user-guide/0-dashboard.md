# Dashboard

The home page after login. Use it to confirm device status and open feature pages.

## Dashboard Panels

<img src="https://resources.camthink.ai/wiki/img/neoeyes-ne503-series/user-guide/dashboard/qs-dashboard-overview.png" />

| Panel | Shows | Entry |
|:--|:--|:--|
| Device Status | Time, uptime, SoC/board temperature | — |
| CPU / NPU / Memory / Storage | Resource usage | Check first when load is abnormal |
| Stream Preview | Live camera feed | **Go to Media** |
| Applications | App status and resource usage | **View all** |
| Gyroscope Calibration | Pitch, Roll, and level status | Mounting angle / EIS check |
| Monitor | CPU, NPU, memory, and other trends | Locate periodic load, stutter, or frame drops |
| Device Info | Device name, IP, MAC, version, and build date | Share with support |

A live preview confirms that the camera and image pipeline are working. If resources approach their limits or temperature keeps rising, check app load and installation conditions.
