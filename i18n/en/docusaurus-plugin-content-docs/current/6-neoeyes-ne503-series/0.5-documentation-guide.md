# Documentation Guide

Choose an entry point by task. You do not need to read every page.

## Choose by role

| Role | Goal | Recommended path |
|:--|:--|:--|
| Evaluator / first deployment | Evaluate the product and bring the device online | Product evaluation: [Product Information](./0-overview.md) → [Hardware Specifications](./2-hardware-guide/0-specifications.md); First deployment: [Quick Start](./1-quick-start.md) |
| Device administrator / operator | Configure, maintain, and secure the device | [Quick Start](./1-quick-start.md) → [Dashboard](./2-user-guide/0-dashboard.md) → [Device Maintenance](./2-user-guide/5-device-maintenance.md) → [Security Hardening](./2-user-guide/7-security-hardening.md) |
| App developer | Build and deploy an AI container app | [Hello World](./4-application-guide/2-cookbook/0-hello-world.md) → [Person Detection](./4-application-guide/2-cookbook/2-person-detection.md) → [Cookbook: Parking Lot](./4-application-guide/2-cookbook/1-parking-lot.md); see [Resources](./4-application-guide/3-resources.md) for SDK/API references |
| System integrator | Integrate video streams, AI events, and device-management interfaces | [Quick Start](./1-quick-start.md) → [Video and Imaging](./2-user-guide/1-media-and-image.md#rtsp-integration); see [Resources](./4-application-guide/3-resources.md) for REST API and Event Bus references |
| Model engineer | Import or convert and deploy HEF models | Existing HEF: [AI Apps and Models](./2-user-guide/2-applications-and-models.md); conversion required: [Model Training and HEF](./4-application-guide/4-model-training-and-hef.md) → [AI Apps and Models](./2-user-guide/2-applications-and-models.md) |
| Platform software developer | Build and install platform software, flash the system, and update MCU firmware | Platform build: [System Architecture](./3-software-guide/0-system-architecture.md) → [Developer Guide](./3-software-guide/1-developer-guide.md#2-start-the-docker-build-environment); software deployment: [Software Deployment](./3-software-guide/3-software-deployment.md); system and firmware flashing: [System Flashing](./3-software-guide/2-system-flashing.md); see [Resources](./4-application-guide/3-resources.md) for source code, SDK/API, and interface references |
| Hardware engineer | Review boards, interfaces, and wiring | [Hardware Specifications](./2-hardware-guide/0-specifications.md) → [Core Board Connection](./2-hardware-guide/1-core-board-connection.md) → [AIPC Board Connection](./2-hardware-guide/2-aipc-board-connection.md) |
