# Interface Board

接口板通过独立 MCU（STM32G0B0RET6）管理外部 IO、电源及外设控制，通过 UART0 与核心处理板通信。

## 功能总览

**对外接口** — 设备外壳上暴露给用户的接口：

| # | 功能 | 说明 | 类别 |
|:--|:-----|:-----|:-----|
| 1 | Alarm I/O | 报警输入/输出 | 整机接口 |
| 2 | RS-485 | 串行通信总线 | 整机接口 |

**内部板载资源** — 已实现功能：

| # | 功能 | 芯片/模组 | 说明 | 类别 |
|:--|:-----|:----------|:-----|:-----|
| 3 | IR-CUT 驱动 | IR-CUT 器件 | 日夜滤光片切换 | 内部 |
| 4 | 光敏检测 | 光敏电阻 | ADC 环境光采样 | 内部 |
| 5 | 红外灯板驱动 | 外接灯板 | 近/远红外 PWM | 内部 |
| 6 | LENS Driver | AN41908A-VBA | SPI 镜头驱动 | 内部 |
| 7 | 系统指示灯 | — | 蓝色状态 LED | 内部 |
| 8 | 温度传感器 | LMT87DCK | ADC 温度采样 | 内部 |
| 9 | 双向复位 | SN74LVC1G14DCK + PD8 | SoC 复位 MCU（芯片）/ MCU 复位核心板（PD8） | 内部 |
| 10 | RTC | 法拉电容 | VBAT 断电保持 | 内部 |

**内部预留资源** — 预留功能，暂未启用：

| # | 功能 | 芯片/模组 | 说明 | 类别 |
|:--|:-----|:----------|:-----|:-----|
| 11 | 雷达供电使能 | — | PB0 电源控制 | 内部预留 |
| 12 | 双光灯板驱动 | 外接灯板 | 白光/红光 PWM | 内部预留 |
| 13 | 风扇驱动 | — | 12V 风扇使能 | 内部预留 |
| 14 | 加热器 | — | 12V 加热器使能 | 内部预留 |

**调试接口** — 开发/调试使用：

| # | 功能 | 说明 | 类别 |
|:--|:-----|:-----|:-----|
| 15 | ST-LINK | SWD 调试口 | 调试接口 |
| 16 | 调试串口 UART1 | USART1 | 调试接口 |

## 对外接口

### Alarm I/O

设备外壳报警输入/输出接口。

| 引脚 | 功能 | 备注 |
|:---|:---|:---|
| PB13 | Alarm_IN0 | 外部报警输入 0 |
| PB14 | Alarm_IN1 | 外部报警输入 1 |
| PA8 | Alarm_OUT0 | 报警输出 0（电平输出） |
| PA9 | Alarm_OUT1 | 报警输出 1（与 USART1_TX 复用） |

### RS-485

设备外壳 RS-485 串行通信接口。

| 引脚 | 功能 |
|:---|:---|
| PC4 | RS485_TXD3（发送） |
| PC5 | RS485_RXD3（接收） |
| PB1 | RS485_EN（收发使能） |

## 内部板载资源

### IR-CUT

IR-CUT 日夜滤光片驱动。

| 引脚 | 功能 | 备注 |
|:---|:---|:---|
| PB8 | IR_CUT_EN（IR-CUT 驱动使能） | 支持 auto / day / night 三模式切换 |

### 光敏检测

光敏电阻 ADC 采样，用于环境光阈值判断，驱动日夜模式自动切换。

| 引脚 | 功能 | 备注 |
|:---|:---|:---|
| PA1 | PD_ADC（ADC1_IN1，光敏电阻采样） | 环境光阈值判断 |

### 灯板驱动

接口板通过 PWM 控制外部灯板（独立物理模组，通过连接器接入）。

**红外灯板（近红外/远红外）：**

| 引脚 | 功能 |
|:---|:---|
| PC9 | PWM_Far（远红外 PWM） |
| PC8 | PWM_Near（近红外 PWM） |

### LENS Driver（AN41908A-VBA）

MCU SPI1 接口控制 AF 自动变焦与自动对焦镜头模组。SoC 侧 SPI CS1 也连接同一芯片（默认控制路径），MCU 侧负责镜头归零与限位保护。

| 引脚 | 功能 |
|:---|:---|
| PA5 | SPI1_CLK（SPI 时钟） |
| PA6 | SPI1_MISO（SPI 主入从出） |
| PA7 | SPI1_MOSI（SPI 主出从入） |
| PA4 | SPI1_CS（SPI 片选） |
| PB3 | LENSPOWER_EN（镜头电源使能） |
| PD6 | F_RST（Focus 复位） |
| PD5 | Z_RST（Zoom 复位） |
| PD4 | RSTB（总复位） |
| PD3 | PLS2（步进控制 2） |
| PD2 | PLS1（步进控制 1） |
| PD1 | VD_FZ（垂直驱动 Focus/Zoom） |
| PD0 | LS_FZ（限位开关 Focus/Zoom） |

### 系统指示灯

| 引脚 | 功能 | 备注 |
|:---|:---|:---|
| PD9 | SYS-LED（系统状态指示灯） | 蓝色，MCU 直接控制 |

### 温度传感器（LMT87DCK）

| 引脚 | 功能 |
|:---|:---|
| PB2 | Temp_ADC（温度 ADC 采样） |

### 主板复位

MCU 通过 PD8 控制核心处理板复位。反向地，SoC 也可通过 H_GPIO_18（SN74LVC1G14DCK）复位本 MCU（详见 [Core Board](./1-core-board-connection.md)）。

| 引脚 | 功能 |
|:---|:---|
| PD8 | POWER_RST（核心处理板复位控制） |

### RTC

MCU VBAT 外接法拉电容维持 RTC 运行，并同步至核心处理板系统时间。

| 功能 | 说明 |
|:---|:---|
| RTC 电源 | VBAT 外接法拉电容 |
| 时间同步 | MCU RTC 同步至核心处理板 |
| 断电保持 | 电容维持 RTC 运行 |

| 引脚 | 功能 |
|:---|:---|
| PB0 | Radar_EN（雷达电源使能） |

### 双光灯板驱动

| 引脚 | 功能 |
|:---|:---|

| PB5 | PWM_W（白光 PWM） |
| PB6 | R_CTL（红光开关控制） |
| PB7 | W_CTL（白光开关控制） |

### 风扇驱动

| 引脚 | 功能 | 备注 |
|:---|:---|:---|
| PB9 | FAN_EN（风扇使能） | 12V |

### 加热器

| 引脚 | 功能 | 备注 |
|:---|:---|:---|
| PA15 | HEAT_EN（加热器使能） | 12V |

## 调试接口

### ST-LINK

MCU SWD 调试口，用于固件烧录与在线调试。

| 引脚 | 功能 |
|:---|:---|
| PA14 | SWDCLK / BOOT0 |
| PA13 | SWDIO |

### UART1（调试串口）

| 引脚 | 功能 |
|:---|:---|
| PA10 | USART1_RX（接收） |
| PA9 | USART1_TX（发送） | 与 Alarm_OUT1 功能互斥，同一时刻只能使用其一 |
