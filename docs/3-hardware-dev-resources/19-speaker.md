# Speaker

## 概览

华龙电子 HDK-302008ZA-3C13 是一款 30mm × 20mm 方形动态扬声器，额定功率 1.5W，阻抗 8Ω，灵敏度 90dB。该喇叭带有 1.2mm 前背胶，便于贴装固定，适用于智能终端、安防设备、 IoT 网关等需要语音提示或报警输出的嵌入式设备。

![Speaker-HDK302008](https://resources.camthink.ai/wiki/img/hardware-dev-resources/speaker/speaker-hdk302008.png)

## 1. 产品概述

### 1.1 产品特点

- **方形微型设计**：30mm × 20mm 紧凑尺寸，适合空间受限的嵌入式设备
- **前背胶固定**：1.2mm 背胶，简化安装流程
- **高灵敏度**：90dB SPL (0.5W/0.1m)，在低功率下即可获得足够的音量
- **宽频响应**：Fo(1000Hz) ~ 20KHz 频率范围，覆盖人耳主要听觉频段
- **RoHS 合规**：符合环保要求

### 1.2 NE301 应用场景

在 NE301传感器扩展板中，扬声器作为**本地告警和语音反馈输出设备**，可在检测到事件时播放告警音效，或通过语音播报告警设备状态。结合 PIR/雷达等传感器触发，实现完整的"检测—抓拍—告警"闭环。

| 应用场景 | 说明 |
|:---|:---|
| 安防告警 | 检测到入侵事件后播放告警音效，现场 deterrence |
| 状态通知 | 设备上线/离线/异常时播放语音提示音 |
| IoT 网关 | 接收远程指令后播放语音反馈，确认操作执行 |
| 工业设备 | 传感器数据超阈值时播放报警提示音 |

| 端子 | 标识 | 功能描述 |
