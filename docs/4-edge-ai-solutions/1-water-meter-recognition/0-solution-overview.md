# 方案概述
## 场景与痛点
- ＜场景:哪些表计、什么环境(泵房/井盖内/楼道)、现有人工抄表的问题＞

## 方案架构
- 架构图:NeoEyes 相机 → Wi-Fi/Cat.1 → NeoMind 平台 → 营收系统

## 软硬件清单
| 组件 | 型号/规格 | 数量 | 说明 |
|---|---|---|---|
| 相机 | NE301 / NE101 | 1 台/表 | 依据安装距离与供电条件选型 |
| 平台 | NeoMind | 1 套 | 设备管理 + 图像识别 + 抄表数据输出 |

## 效果与指标
- ＜识别准确率、覆盖率、单表成本对比人工抄表＞
