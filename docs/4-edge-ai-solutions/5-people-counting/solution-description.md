*Line Crossing 实时页面:目标穿越计数线 → IN/OUT 计数即时更新 → 过线事件入表,全程端侧完成*

## 方案背景

客流与流量的越线统计需求广泛存在:门店要掌握进出人数,通道要识别流向,园区出入口要分析高峰低谷。传统方案的成本都不低:闸机、红外对射需要硬件采购与施工改造,宽通道场景还容易漏计;云端视频分析按路数收取订阅费,且画面需要流出内网;自建平台则意味着一套服务器与平台许可,部署周期以周计。

多数点位需要的并非平台级高精度,而是**部署快、成本低、当天可用**。

## 方案介绍

本方案的思路是:**一台低成本相机 + 一条计数线,把"过线"变成结构化数据。**

在点位部署一台 CamThink **NeoEyes NE301** 边缘 AI 相机(STM32N6,0.6 TOPS,模块化设计),安装 **line-crossing** 应用后在 Web 页面完成全部配置:先部署目标检测模型并设定目标类别,再在实时画面上**两次点击画出计数线**,拖动端点微调,一键**交换进出方向**。应用在相机端完成目标检测、多目标跟踪与越线判定,实时输出双向计数;按设定的统计周期生成窗口报告,经 **MQTT / Webhook** 直接推送给业务系统。

统计对象由**端侧检测模型**决定:相机预置人形检测模型,装上应用即可统计人流;有自定义目标时,**按场景训练专属检测模型并部署到相机**——训练、量化、部署流程全部开源,统计自定义目标不需要修改方案代码。

整个过程在相机端闭环:检测、计数、生成报告一机完成;画面不出本地网络,业务系统只接收轻量的计数结果。

## 方案组成(BOM)

| # | 组成 | 型号 / 规格 | 数量 | 职责 |
|---|---|---|---|---|
| 1 | 边缘 AI 相机 | NeoEyes **NE301**(通讯模组按点位选 Wi-Fi 6 / Cat-1 / PoE) | 每点位 1 台 | 端侧检测、跟踪与越线计数 |
| 2 | line-crossing 应用 | `.neapp` 应用包,随方案交付 | 1 套 | 画线配置、实时统计、窗口报告生成 |
| 3 | 供电与网络附件 | Type-C 电源 / PoE;Wi-Fi 接入点 / PoE 交换机 / SIM 卡 | 按需 | 相机部署配套 |
| 4 | 业务系统接收端 | MQTT Broker(含 MQTTS)或支持 Webhook 的 HTTP 服务 | 1 套 | 接收窗口报告,进入业务流程 |

> 低成本起步:1 台 NE301(Type-C 供电 + Wi-Fi)+ line-crossing 应用 + 一个现有 MQTT/Webhook 接收端即可完成部署,无需闸机施工、无需服务器。

## 工作流程

1. **部署模型并设定目标** — 按统计对象上传指定检测模型(Model Zoo 示例或自训模型),并选择对应目标类别;使用预置人形模型可直接统计人流
2. **画线定义口径** — 在实时画面上两次点击画出计数线并指定外侧方向,拖动端点微调,保存后生效
3. **端侧检测跟踪** — 相机对画面中的目标持续检测与跟踪,输出稳定轨迹
4. **越线判定计数** — 轨迹穿过计数线时按方向计进入/离开,累计计数断电保持
5. **窗口统计** — 按统计周期(可配 1~1440 分钟)汇总本周期进/出,生成窗口报告
6. **上报对接** — 报告经 MQTT / Webhook 推送业务系统;断网期间容量内暂存、恢复后尽力补发

## 核心特点

**灵活部署**

- **画线即用**:两次点击即可定义统计口径,无需标定、无需训练,修改计数线即时生效
- **供电与联网简单**:Type-C 电源直供,或 PoE 一线同时解决供电与以太网;通讯模组(Wi-Fi 6 / Cat-1 / PoE)按点位条件选配
- **端侧单机闭环**:应用运行在相机内,无需服务器、无需平台软件,点位迁移时拆卸重装即可

**检测模型可定制**

- **自训模型部署**:按场景训练专属检测模型,部署到相机即可统计自定义目标,训练与部署流程全开源
- **Model Zoo 示例模型**:官方模型库提供场景调优的视觉模型(PT / ONNX / TFLite),示例模型可直接下载使用
- **精度可持续优化**:出厂人形模型提供可用基线;基于现场样本持续训练、优化并重新部署,统计精度随迭代逐步提升
- **端侧推理**:0.6 TOPS NPU 本地完成检测与计数,模型运行在相机内,不依赖云端

**低成本**

- **一台相机起步**:无闸机采购、无施工改造,当天完成部署
- **无云端订阅**:计数结果直推现有业务系统,无按路数计费,无视频外发带宽成本
- **数据本地化**:画面与计数全部保留在本地网络,数据资产自主可控

## 方案效果

- 单点位成本低至一台相机,当天部署即可产出数据,替代人工点数
- 更换统计场景仅需更换检测模型并重新画线,统计框架保持不变
- 进出流量按窗口自动入库,为排班、陈列与效能分析提供连续数据
- 统计精度受安装角度、光照与目标密集程度影响,面向流量趋势分析场景;通过现场样本持续训练优化模型并重新部署,精度可逐步提升,部署时以现场实测为准
