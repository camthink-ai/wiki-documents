# 方案概述
## 场景与痛点
- 实时在场人数不可见、高峰排队、器械利用率无法量化、安全事故响应慢>

## 方案架构
- 入口相机(客流) + 器械区相机(行为) → NeoMind → 门店大屏/管理后台

## 软硬件清单
| 组件 | 型号 | 数量 | 位置 |
|---|---|---|---|
| 客流相机 | NE503 / NE301 | 出入口 | 顶装俯拍 |
| 平台 | NeoMind | 1 套 | 云端/本地 |

## 效果与指标
- 客流统计准确率、超员告警响应时间、器械利用率报表
