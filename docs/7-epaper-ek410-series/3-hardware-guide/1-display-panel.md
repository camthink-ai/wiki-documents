# Display Panel Characteristics

本页说明 EK410 所用 7.09″ E Ink Spectra 6 面板的显示特性，以及固件层面的帧格式约定，供内容制作与二次开发参考。

## 面板特性

| 项目 | 规格 |
| :--- | :--- |
| 技术 | E Ink Spectra 6 六色电子纸 |
| 尺寸 | 7.09″ |
| 原生分辨率 | 1200 × 1600（竖向），双驱动 IC 左右分布 |
| 逻辑分辨率 | 1600 × 1200（横向，固件统一以此坐标处理） |
| 可显色 | 黑 / 白 / 黄 / 红 / 蓝 / 绿 |
| 驱动接口 | 标准 SPI，双片选（CS0 / CS1 各驱动半幅） |

## 六色色码

帧缓冲中每像素 4bpp，每字节 2 像素（高半字节在前）。色码约定：

| 颜色 | 色码（低 4 位） |
| :--- | :--- |
| 黑 | `0` |
| 白 | `1` |
| 黄 | `2` |
| 红 | `3` |
| 蓝 | `5` |
| 绿 | `6` |

例如全屏白色对应的填充值为 `0x11`；一个字节的合法组合为上表中任意两个色码的拼接。

## 原生帧格式

`uploadFrame` / `lastFrame` 使用同一布局：

- 总长 **960000 字节**（1600 × 1200 × 0.5 字节）。
- 面板物理为竖向 1200×1600、双 IC（CS0 / CS1）各写半幅；固件在写入前做 **90° 旋转与半幅拆分**。
- 上层应用按逻辑画布 **1600 宽 × 1200 高、逐行、4bpp** 组织即可；手工组帧请用仓库 `tools/frame_convert.py`（真实 CS0/CS1 布局），不要假设「纯横向缓冲直接写屏」。

## 刷新行为

- **全刷**：每次内容更新都是一次全板刷新，约 20–40 秒；刷新由显示任务异步执行，期间新请求返回 `render busy`。
- **画面保持**：刷新完成后断电画面依然保持，静态显示不耗电。
- **事件驱动**：没有连续刷新或局部"播放"概念；更新频率由内容来源（网页操作、URL 刷屏、定时唤醒、MQTT 指令）决定。
- 快照机制：成功的用户刷屏会把原生帧写入 `lastfrm` 分区，供 Web 控制台预览与 API 读取。

## 图片适配建议

- 制作整屏图片时按 **1600 × 1200** 横向比例构图；非该比例的图片会按所选适应方式裁切或信箱适配。
- 照片 / 渐变交给 Web 控制台的 Floyd–Steinberg 抖动量化处理，避免手工做色块化。
- 文字与细线条建议使用编辑器模式（矢量合成），比位图缩放更锐利。
- 设备侧拉图仅支持 **baseline** JPEG / PNG / 原生帧；渐进 JPEG 会失败；WebP 需在平台侧预先转换。体积与跳转限制见[内容显示](../2-user-guide/1-display-content.md)。
